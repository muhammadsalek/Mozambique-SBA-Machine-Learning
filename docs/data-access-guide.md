# DHS Data Access Guide (Mozambique 2022–2023)

## Scope

This guide describes how authorized researchers can request access to DHS microdata. This repository does **not** contain DHS microdata.

## Access Path for Authorized Researchers

1. Create a user account at the DHS Program data portal.
2. Submit a data request describing:
   - research title and objectives,
   - country and survey selection (Mozambique DHS 2022–2023),
   - requested recode files,
   - intended analytical use.
3. Wait for review and approval from The DHS Program.
4. Download approved datasets from your account workspace.
5. Store data securely according to institutional and DHS usage terms.

## Compliance Requirements

- Use DHS data only for approved research purposes.
- Do not redistribute raw microdata.
- Do not upload participant-level data to public repositories.
- Follow local IRB/ethics and institutional data-governance requirements.

## Recommended Local Setup

- Keep raw DHS files outside version control.
- Use local paths or environment variables for data locations.
- Commit only scripts, documentation, and non-sensitive derived summary outputs allowed by DHS terms.

## Confirmation Note

If project-specific data-handling steps differ from this guide, update this document to match the approved protocol and implemented R scripts.
